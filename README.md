# Muestreo por ruleta (RWS)

Simulador académico de selección proporcional al valor de aptitud, desarrollado con Python, Streamlit y Plotly.

## Ejecutar localmente

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Publicar en Streamlit Community Cloud

1. Crea un repositorio en GitHub y sube `app.py` y `requirements.txt` en su carpeta principal.
2. Accede a https://share.streamlit.io/ e inicia sesión con GitHub.
3. Elige **Create app** y selecciona tu repositorio, la rama `main` y el archivo `app.py`.
4. Despliega la aplicación y comparte su enlace `*.streamlit.app`.

La aplicación necesita conexión a internet cuando se consulta en Streamlit Cloud.
